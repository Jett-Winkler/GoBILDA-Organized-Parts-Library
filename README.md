# GoBILDA-Organized-Parts-Library
This is a parts library of every part gobilda has ever made. It is in the form of a bunch of .zip files and it has proper folder hierarchy that matches the GoBILDA webstie, as well each file is named "part name {SKU}". If it is unupdated or if you use fusion and would like the premade fusion parts library reach out to FTC team 19922 Iron Lions.
